# student-performance-analysis
基于 UCI Student Performance 数据集的成绩分析
pandas 数据清洗与描述统计，matplotlib/seaborn 绘制成绩分布、相关性热力图与性别对比箱线图，并用随机森林回归挖掘影响期末数学成绩（G3）的关键因素。
# 分析方法：
## 数据预处理
- 以 `;` 为分隔符读取数据，查看数据类型、描述性统计与缺失值分布
- 删除缺失样本与重复行；按 G3 的合法范围（0–20）过滤异常记录
- 对类别变量做 one-hot 编码（`get_dummies(drop_first=True)`），避免虚拟变量陷阱
## 探索性可视化
- G3 分布直方图：观察成绩整体分布与集中区间
- 特征相关性热力图：快速定位与目标强相关的变量
- 性别分组箱线图：比较男女生的成绩中位数与离散程度
## 随机森林回归建模
- 以 G3 为目标变量，其余编码后特征为自变量
- 按 8:2 划分训练集与测试集（`random_state=42`），默认参数训练 `RandomForestRegressor`
- 输出特征重要度排序，定位影响期末成绩的主要因素
# 主要结论
| 排名 | 特征 | 重要度 |
|---|---|---|
| 1 | G2（第二次阶段成绩） | 0.793 |
| 2 | absences（缺勤次数） | 0.110 |
| 3 | reason_home（家庭原因择校） | 0.021 |
| 4 | age（年龄） | 0.010 |
| 5 | G1（第一次阶段成绩） | 0.006 |

- **前一次成绩是最强信号**：G2 单独贡献了约 79% 的重要度，说明学业表现具有很强的连续性，早期成绩下滑值得尽早干预。
- **出勤与成绩显著相关**：缺勤次数重要度约 11%，是除成绩外最值得关注的行为指标。
- **家庭与社会经济变量影响有限**：在随机森林的重要度排序中，父母教育程度、家庭支持等特征排名靠后，其作用更多是被阶段成绩间接吸收。
